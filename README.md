# Cap Horizon Voyages — site vitrine

Site vitrine de démonstration pour une agence de voyages basée à Marrakech. Les offres, prix et coordonnées sont fictifs.

**Démo en ligne :** https://zineb1904.github.io/site-vitrine-voyage/

## Pages

- **Accueil** : tableau des départs interactif et atouts de l'agence
- **Séjours** : une fiche par destination avec programme jour par jour et prestations incluses
- **Contact** : formulaire de demande de devis avec contrôle des champs, destination préremplie depuis la fiche du séjour

## Technologies

HTML, CSS et JavaScript, sans framework. Design adaptatif : ordinateur, tablette et mobile.

## Lancer en local

Ouvrir `index.html` dans un navigateur.
